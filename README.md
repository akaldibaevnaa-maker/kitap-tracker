# KitapTracker — «Кітап әлеміне саяхат»

Мектеп оқушыларының кітап оқуын ойын арқылы қызықтыратын, оқығанын түсінуге, өз ойын еркін айтуға және тұрақты оқу әдетін қалыптастыруға көмектесетін интерактивті толыққанды веб-платформа.

### 📋 Жобаның ресми төлқұжаты:
- **Мектеп:** №290 орта мектеп (2026 жыл)
- **Бағдарлама авторы:** Құлахметова Аягөз (11-сынып оқушысы, №290 орта мектеп)
- **Жетекшісі:** Аскарова Айнур Калдыбаевна
- **Ғылыми кеңесші:** Құлмырзаев Нұрлан Серікұлы (Қорқыт ата атындағы Қызылорда университеті, Жасанды интеллект институты директоры)

## 🚀 Жылдам іске қосу

Платформа **сыртқы тәуелділіксіз (zero-dependency)** жұмыс істейді. Node.js 22/24 құрамындағы кірістірілген SQLite (`node:sqlite`) мен кірістірілген модульдер қолданылған.

```bash
# 1. Серверді іске қосу
npm start
# немесе:
node server/index.js

# 2. Браузерде ашу
http://localhost:3000
```

Сервер алғаш рет қосылғанда дерекқор автоматты түрде жасалып, барлық сынақ деректері (демо авторлық әңгіме, 7 ойын тапсырмасы, демо мұғалім және демо оқушылар) дерекқорға енгізіледі.

### Автоматты сынақтарды жүргізу:
```bash
npm test
# немесе:
node --test tests/acceptance.test.js
```

## 🌟 1. Негізгі тұжырымдама және оқу циклі

Оқушы — кітап әлемін зерттеуші. Әр кітап — жаңа саяхат, ал оқу тапсырмалары — сол саяхаттағы миссиялар.

```
Кітап таңдау → Жеке мақсат қою → Мәтіннен үзінді оқу → Ойын тапсырмасын орындау → Ойыңмен бөлісу → Жетістігіңді көру → Саяхатты жалғастыру
```

## 📱 2. Оқушыға түсінікті құрылым (5 бөлім)

Оқушының басты мәзірінде тек бес нақты бөлім бар:

1. **«Менің әлемім» (Басты кабинет):**
   Оқушы кірген бойда үш негізгі сұраққа бірден жауап алады:
   - *Қазір қай кітапты оқып жүрмін?* (мұқабасы, оқылған беті және прогресс бары);
   - *Бүгін не істеймін?* (күнделікті нақты 1 миссия және «Оқуды жалғастыру» басты батырмасы);
   - *Қандай жетістікке жеттім?* (соңғы ашылған марапат, жиналған XP және өзін өз нәтижесімен салыстыратын жігерлендіру сөздері).
   - Апталық оқу күнтізбесі (дүйсенбіден жексенбіге дейінгі жеке мақсат).

2. **«Кітап сөресі»:**
   - Кітаптарды сынып деңгейі, тіл, жанр және қызығушылық бойынша сүзу және іздеу;
   - Жеке сөре мәртебелері: *«Оқығым келеді»*, *«Оқып жатырмын»*, *«Аяқтадым»*;
   - Каталогта жоқ кітапты қолмен қосу мүмкіндігі (жалпы бет саны нақты басылымға сәйкес енгізіледі).

3. **«Ойын алаңы» (Оқылған кітаппен байланысты 7 ойын түрі):**
   - **«Оқиғалар тізбегі»:** Оқиғаларды дұрыс ретке орналастыру (сүйреп апару және ↑/↓ батырмалары арқылы).
   - **«Кейіпкерді таны»:** Берілген әрекет немесе сипаттама бойынша кейіпкерді табу.
   - **«Кім айтты?»:** Мәтіндегі сөздерді кейіпкерлермен сәйкестендіру.
   - **«Сөз қазынасы»:** Мәтіндегі жаңа сөзді мағынасымен сәйкестендіріп, өз сөйлемінде қолдану.
   - **«Дәлелді тап»:** Берілген пікірді қолдайтын мәтін үзіндісін таңдау.
   - **«Кейіпкердің таңдауы»:** Кейіпкердің шешімін талдап, өз позициясын дәлелдеу.
   - **«Шығармашылық шеберхана»:** Кітапқа жаңа мұқаба ойлап табу, кейіпкерге хат жазу немесе басқа аяқталу ұсыну.

4. **«Ортақ миссия»:**
   - Сынып бірлесіп өсіретін виртуалды **«Білім бағы»** (ортақ оқу күндері мен қабылданған пікірлер бойынша ағаштар мен жемістердің өсуі);
   - Әркімнің өз мүмкіндігінше қосқан жеке үлесі. Бір оқушының екінші оқушымен жарысып салыстырылуына жол берілмейді, тек сыныптың ортақ жеңісі көрсетіледі.

5. **«Жетістіктерім»:**
   - Саяхат картасының 5 кезеңі: *«Бастау қақпасы» → «Кейіпкерлер мекені» → «Оқиғалар жолы» → «Ой қазынасы» → «Кітап шыңы»*;
   - Марапаттар каталогы: жетістік белгілері (значоктар), аватар әшекейлері (үкі қауырсыны, жұлдыз, қызғалдақ, бас киім), сөреге арналған виртуалды заттар (шамшырақ, глобус, гүл, домбыра);
   - Ашық ұпай кітабы және ұпай жинау ережелері.

## 👩‍🏫 3. Мұғалім кабинеті (Бөлек кеңістік)

- **4 негізгі көрсеткіш:**
  1. *Оқу белсенділігі* (соңғы 7 күндегі оқырман саны, оқу күндері, минуттары);
  2. *Кітаптар бойынша прогресс* (қай кітапты қанша оқушы оқып жүр, орташа оқу пайызы);
  3. *Тапсырмалар нәтижесі* (орындалған ойындар саны, орташа әрекет саны);
  4. *Тексеруді күтетін жауаптар* (оқушылардың рефлексиялары мен шығармашылық жауаптары).
- **Сыныптар мен кодтар:** Сынып құру, шақыру кодын алу, оқушының 4 таңбалы PIN-кодын бір басумен қалпына келтіру;
- **Тапсырма құрастырушы:** Кез келген кітапқа арнап ойын тапсырмаларын құру;
- **«Үзіндіден жоба» (Ереже бойынша құрал, AI емес):** Мұғалім салған үзіндіден сөйлемдерді талдап, жоба дайындайды. Мұғалім тексеріп мақұлдағаннан кейін ғана оқушыға көрінеді;
- **Оқушы ретінде алдын ала қарау:** Тапсырманың қалай жұмыс істейтінін оқушы көзімен көріп, нәтижесін тексеру;
- **Жауаптарды тексеру:** «Қабылдау» (+20 XP беру) немесе «Қайтару» (нақты түзету кеңесімен);
- **CSV есеп жүктеу:** Оқушылардың белсенділік есебін Excel үшін UTF-8 форматында жүктеу. Ойын ұпайының пәндік бағаға автоматты айналдырылмайтыны ескертілген.

## ⚖️ 4. Ұпай және Педагогикалық этика

- **Ашық ережелер:**
  * Күндегі алғашқы оқу жазбасы: +10 XP;
  * Оқу ойынын алғаш аяқтау: +10 XP;
  * Мұғалім қабылдаған рефлексия: +20 XP;
  * Кітапты толық аяқтау: бір рет +50 XP.
- **Шектеулер мен қорғаныс:**
  * Оқушы бір күнде екінші немесе үшінші жазба жасағанда артық ұпай берілмейді;
  * Қайта жаттығуға рұқсат бар, бірақ бір тапсырмадан шексіз ұпай жиналмайды;
  * Бір күн оқымағаны үшін ұпай шегерілмейді немесе қорқытатын кері санақтар қойылмайды;
  * Ақылы марапаттар, ұпай сатып алу немесе кездейсоқ ұтыстар (лутбокс) жоқ;
  * Басқа оқушылармен ашық рейтинг жарысы негізгі экранға шығарылмайды — басты назар жеке дамуға және сыныптың ортақ жеңісіне бағытталған.

## 🛡️ 5. Қауіпсіздік және деректер құпиялығы

- Оқушыдан артық жеке деректер (email, телефон нөмірі) сұралмайды.
- Оқушы жүйеге тек бүркеншік аты, сынып коды және 4 таңбалы құпия PIN арқылы кіреді.
- PIN-кодтар `scrypt` криптографиялық хэштеуімен сақталады.
- Сессиялар `HttpOnly` және `SameSite=Lax` cookie арқылы басқарылады.
- Өзгерту енгізетін әрбір сұраныс CSRF-ке қарсы `X-KT: 1` арнайы тақырыбымен қорғалған.
- Мұғалім тек өз сыныбының оқушылары мен жауаптарын көре алады, басқа сыныптың деректеріне рұқсат қатаң бұғатталған (403 Forbidden).
